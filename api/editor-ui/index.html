Cartão de fechamento

Últimos 3 segundos

Só vale com Trilha sonora ligada. Música da biblioteca local (Mixkit, licença livre pra uso comercial), baixada na instalação. Sem ela, o vídeo sai sem trilha.

Zoom nos cortes alterna o enquadramento; aproximação automática avança devagar; câmera acompanha o rosto no terço superior; clarão começa dois frames antes do corte. Os liga-desliga acima controlam esses quatro elementos.

Limites do render automático: cor personalizada, música com IA e observações são guardadas como escolhas, mas o servidor não as aplica. Legenda “Nenhum” não é aceita pelo render.
